About

I’m Nicolas Nino (NN), a data scientist & simulation engineer building a physics‑accurate quadcopter environment in Unreal Engine as a lightweight alternative to legacy simulators. My work spans controller design (cascaded PID & nonlinear), sensor modeling (IMU, GPS, barometer, magnetometer), PX4/ROS2 integration, and sim‑to‑real validation.

I care about correctness, clean interfaces, and reproducible results. Recruiters and professors can quickly scan this page to see the project broken into practical, reviewable modules.

Highlights
  • Unreal‑native plugin architecture (Simulation Manager · Drone Manager · Time Controller)
  • PX4 HITL/SITL bridges; ROS2 & ZeroMQ I/O surfaces
  • Noise‑aware sensor models and unit‑consistent transforms (FRU ↔ NED)
  • Extensible UI/HUD with profiling and debugging overlays

Unreal Project — Modular Breakdown

Dynamics

Drone Model

Rigid‑body quadcopter with tuned mass/inertia, thrust/drag models, prop response, and frame conventions aligned to NED.

Controls

Accurate PID Calculations

Cascaded rate/angle/position loops with anti‑windup, derivative filtering, and consistent time‑step integration.

Input

Gamepad Support

Configurable mappings and dead‑zones for manual flight; deterministic input path for repeatable testing.

Rendering

High‑Fidelity Graphics & Map Design

Optimized levels and post‑processing for visibility of state, without compromising physics update cadence.

Sensors

Accurate Sensor Modeling

IMU, GPS, magnetometer, barometer with bias/drift/noise; configurable rates and covariance for estimators.

Integration

PX4 Integration

Bridges for HITL/SITL, MAVLink topic mapping, frame conversions, and time sync with the sim clock.

Middleware

ROS2 Integration

Publish/subscribe interfaces for telemetry and control; launch‑friendly config and message schema parity.

I/O

ZeroMQ Integration

Lightweight sockets for external tools, logging, and reinforcement learning loops.

Roadmap

Future Work

Weather & wind dynamics, customizable HUD, expanded failure modes (motor loss), and sim‑to‑real studies.
