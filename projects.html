Unreal Drone Simulation — Deep Dive

A modular simulation focused on accurate flight dynamics, realistic sensors, and clean interfaces. This page highlights the core pillars with short explanations and visual evidence.

PX4 + ROS 2 Integration

Clean bridges for telemetry and control with robust update timing. I maintain strict unit and frame conventions (UE cm ↔ SI meters; FRU vs NED) and use structured topics/services for clarity.

  • HITL/SITL tested pathways for command + state feedback.
  • Thread-safe data mirroring; no UObjects accessed off game thread.
See a short PX4/ROS 2 demo

Accurate Flight Dynamics

Cascaded PID with validated thrust/drag models and sane defaults. Careful unit conversions, inertia setup, and spawn stability logic minimize oscillations and make behavior repeatable.

  • Consistent SI conversions, moment arms, and motor response curves.
  • Deterministic initialization with robust recovery from transients.
Watch a stability test

Sensor Suite & Fusion

IMU, GPS, barometer, and magnetometer signals with tunable noise models and estimator-ready covariances. Outputs align with real-world magnitudes and directions for downstream filters.

  • Noise models calibrated to expected real-world variance.
  • Time-aligned streams for EKF/UKF pipelines.
Sensor fusion clip

Gamepad + UI

Controller mappings for manual flight, with a focused HUD for state, mode, and warnings. Designed to be readable and minimal so you can test quickly without clutter.

  • Flexible input curves and rate limits.
  • Lightweight HUD with performance-friendly rendering.
Controller pass demo

Extensible Framework & Future Work

Modular managers (Simulation, Drone, Time) with clear responsibilities, making it easy to add weather fields, alternate controllers, or RL training loops without breaking core APIs.

  • Planned: wind/atmospherics, richer HUD, expanded benchmarking.
  • Planned: RL training harnesses and sim-to-real validation suites.
